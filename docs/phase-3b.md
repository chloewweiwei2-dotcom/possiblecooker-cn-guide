# 3B：搜索、筛选、PWA 与离线验收

本轮复用已验收数据，不重做 PDF 审核，不修改官方事实。3A 已通过；3C 尚未开始，未发布公网。

## 搜索与筛选

搜索支持官方中文／英文菜名、功能名称、菜谱食材、说明及技巧标题、参考表食材。英文标题仅取已存原文；搜索索引不包含非官方中式理解。结果标明菜谱、烹饪功能、使用说明、技巧、参考表。

筛选为官方类别、已有功能、食材文字、官方 Cook 上限，支持一键清除。食材输入框精确匹配官方 Ingredients 的中英文文字，不补同义词、不从菜名推断配料。功能筛选不包括技巧中的可选功能。Cook 仅按官方标注比较；8 小时的猪肉大小说明仍保留；未来无法明确解析的范围不强行变为单值。

## 本地验收地址

正式构建：http://127.0.0.1:4173/ 。开发页面 5173 不注册 Service Worker。两个端口属于不同的网站存储空间，收藏、字号、进度不会自动互相迁移，原地址数据未删除。请在 4173 上新增测试收藏及设置后检查持久化。

构建：`npm.cmd run build`。本地预览：`npm.cmd run preview -- --port 4173 --strictPort`。服务仅监听本机，尚无手机可访问的 HTTPS 地址。

## PWA 与离线

Manifest 提供完整中文应用名、中文简称、独立窗口、白色／薄荷绿主题及自有锅具图标（192、512 像素），另提供苹果主屏幕图标。未使用 Ninja Logo。

构建脚本为全部 19 个资源生成版本缓存，约 2.47 MB：应用代码及样式、所有中文内容及英文对照、9 张官方菜品照片、统一占位图、应用图标、Manifest、两份原始 PDF。首次完整缓存才安装成功；失败不替换旧版本。六道缺图菜仍使用占位图，未新增图片来源。

外部产品网站、注册网站和其他外部链接不缓存：不属于本应用资源，也未获授权复制外部内容。Service Worker 自身通过浏览器更新机制加载，不作为普通资源预缓存。

离线状态显示在页面中。已有缓存使用版本内资源；无强制刷新或自动跳步。新版本等待用户到设置主动更新；逐步做菜中不执行更新，其他窗口仍打开时拒绝强制激活。缓存版本变化不删除 localStorage。浏览器清理／回收网站数据仍可能删除缓存及本地数据。

## 用户测试步骤

1. 在电脑 Edge 或 Chrome 中打开 4173 地址，进入设置，等待“主要内容已缓存”。若显示重新打开按钮，点一次。
2. 收藏一道菜、调整字号，并在逐步页面切到第 2 步。
3. 按 F12 打开开发者工具，选择 Network（网络），将网络下拉框从 No throttling（不限速）改为 Offline（离线）。保持该工具打开并刷新页面。
4. 检查离线提示、进度、收藏、字号、菜谱和参考表，试着离线切换下一步。测试完恢复网络下拉框为 No throttling。
5. 安装检查须使用普通浏览器窗口：地址栏安装图标、浏览器菜单，或设置中的安装按钮。Codex 内置浏览器不一定提供系统安装界面。
6. 真实 Android／平板安装、iPhone／iPad 分享→添加到主屏幕、独立窗口与真实飞行模式重启等需以后在手机可访问的 HTTPS 地址验证；本机 127.0.0.1 不能直接作为手机测试地址。
