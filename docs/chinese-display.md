# 中文优先展示规则（第二阶段验收调整）

本次仅修改展示层，不进入第三阶段。官方 JSON、英文原文、来源元数据、审核编号和原 PDF 均不改写；tests/official-data-hashes.json 记录调整前校验值，测试确认一致。

- 页面标题、菜名、食材、说明、警告、技巧、注意事项、表格、来源与读者提示使用中文。
- 功能与实体按钮使用中文在前的对应标签，例如慢炖（SLOW COOK）、开始／停止（START/STOP）。档位统一显示高档／低档，不把原文 HI 擅改为 HIGH。
- 产品名与型号用于识别本应用；来源行按用户示例保留 PDF 页序。
- 单位名称译成中文，不作换算：美制杯、盎司、磅、英寸、汤匙、茶匙、华氏度等；分数、范围和全部数值保持原样。原单位仍在数据层和折叠英文原文中。
- 英文菜名及原文不在默认正文重复展示，可在“查看英文原文”内核对。原文折叠默认关闭。
- 官方说明书／官方菜谱指南作为普通来源名称，使用次要颜色和较小字号。来源链接保留原 PDF 定位。
- 读者页面仅展示影响理解与操作的中文疑点提示，不显示内部编号、审核状态。安全警告仍优先显示。
- 开发核对页保留 22 项完整记录、SR 编号和 SOURCE_REVIEW_REQUIRED；入口收在“设置 → 内容来源 → 开发核对记录”折叠区。
- 数值表的中英重复食材名仅在展示时收为中文，不修改原始单元格。拼写错误仍保存在开发记录及原文中。

检查：47 个页面的渲染、默认可见文字扫描、三种表格状态、数值未变检查、原文件哈希检查；浏览器核实中文呈现、表格切换和原文展开／折叠。
